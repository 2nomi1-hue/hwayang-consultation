# 화양연화 상담 기록 화면

비디오자서전 서비스 화양연화의 상담 기록 입력·미리보기 화면입니다. 외부 라이브러리와 빌드 도구 없이 HTML, CSS, JavaScript로 실행합니다.

## 웹에서 보기

https://2nomi1-hue.github.io/hwayang-consultation/

공개 저장소의 `index.html`은 CSS와 JavaScript를 포함한 단일 파일입니다. 이 PC 작업폴더에는 수정용 HTML·CSS·JS와 동일한 화면의 `dist/index.html`을 함께 보관합니다.

## 사용

1. `index.html`을 브라우저에서 열거나 GitHub Pages에 배포합니다.
2. 역할·상황·목표·걱정·유입 경로·상담 발언을 작성합니다. `가상 예시 채우기`로 앞서 시연한 상담을 불러올 수 있습니다.
3. `기록 미리보기`로 내용을 확인합니다.
4. `기록 JSON 저장`과 `상담 메모 저장`으로 두 파일을 각각 내려받습니다.

입력과 연결 설정은 현재 브라우저 탭의 메모리에서 처리합니다. 임시 연결을 설정하고 전송 버튼을 누르면 가상 상담만 맥미니의 분리된 시연 Wiki로 보냅니다. 실제 고객 상담 접수, 이메일 발송, AI 분석, 로그인 기능은 없습니다. 새로고침하면 입력이 사라지므로 필요한 기록은 파일로 저장합니다. 이름·연락처를 입력하는 필드는 없습니다.

## LLM Wiki 연결

- 내려받은 `.md` → 사용할 Wiki의 `inbox/documents/`
- 내려받은 `.json` → 같은 Wiki의 `inbox/records/`
- **먼저 메모를 넣은 뒤 JSON을 넣습니다.** JSON의 `source_id`가 메모 파일명을 참조하므로 파일명을 임의로 바꾸지 않습니다.
- 기존 수집기가 실행 중이면 다음 확인 주기에 원본 보존·기록 검증·현황 갱신이 이뤄집니다. 감시 프로세스를 중복 실행하지 않습니다.
- 가상 자료는 별도 시연환경에 넣고 `is_demo: true`를 유지합니다. 실제 고객 근거 집계와 구분됩니다.

현재 Wiki는 JSON 기반 근거 저장소입니다. 화면의 역할 선택은 입력 편의를 위한 것이며, 내보내는 `role`은 기존과 같은 문자열입니다. 구매자와 주인공은 개인을 둘로 나누는 고정 속성이 아니라 상담에서의 역할입니다. `기타`를 선택하면 역할을 직접 입력할 수 있습니다.

가설 H1~H8은 담당자가 선택한 연결입니다. 자동 분류나 통과·실패 판정이 아닙니다. 실제 상담 여부도 사용자가 구분하며 이 화면이 진위를 검증하지 않습니다.

## 공개 저장소에 포함되는 것

화면 소스와 명확히 가상으로 표시한 예시만 포함합니다. 운영 Wiki 원본·기관 진행 내역·실제 고객 기록·다운로드한 상담 파일은 포함하지 않습니다. 공개 페이지에서 작성한 내용은 GitHub에 자동 저장되지 않습니다.

## GitHub Pages

저장소 Settings → Pages에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하면 정적 페이지로 배포할 수 있습니다. 별도 서버 기능은 추가되지 않습니다.

## 맥미니 임시 자동 전송 (가상 상담 전용)

1. 가상 상담을 작성하고 미리보기를 만듭니다.
2. `맥미니 임시 연결`에서 HTTPS 수신 주소와 인증키를 입력하고 `연결 확인`을 누릅니다.
3. `가상 상담을 맥미니로 전송`을 누르면 원문·JSON을 수신 폴더에 저장합니다.
4. 화면에서 수집기 현황 반영까지 확인합니다. 저장과 현황 반영은 서로 다른 상태로 표시합니다.

임시 수신기는 실제 상담(`is_demo:false`)을 거부합니다. 운영 Wiki와 별도 폴더를 사용하며 5초 수집기도 그 폴더만 감시합니다. 같은 ID·같은 내용의 재전송은 중복 추가하지 않고, 같은 ID의 다른 내용은 덮어쓰지 않습니다.

설치 파일과 비공개 연결 설정은 맥미니의 `~/.hwayang-intake-demo/`에 보관합니다. `intake-config.json`에는 비밀 인증키가 있으므로 공개 저장소에 올리지 않습니다. 임시 수신기·수집기·터널 PID는 같은 폴더 `pids.json`에 있습니다. 이 연결은 로그인 자동시작을 설치하지 않은 임시 실행입니다.

Cloudflare Quick Tunnel 주소는 임시 주소입니다. 터널이 종료되면 사용할 수 없으며, 고정 운영 주소로 전환하려면 별도 도메인·인증 구성이 필요합니다. [Cloudflare 공식 안내](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)
